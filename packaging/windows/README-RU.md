# Fluffify для Windows (x64)

В архиве уже лежит всё необходимое: ядро Xray встроено в сам клиент,
отдельный `xray.exe` больше не существует.

## Что внутри

| Файл | Назначение |
|---|---|
| `Fluffify.exe` | клиент: TUI + иконка в трее + встроенное ядро Xray |
| `wintun.dll` | драйвер виртуального адаптера для TUN-режима |
| `docs/` | лицензии, документация Xray и эта инструкция |

**TUN и wintun.dll.** Для TUN-режима ядро загружает `wintun.dll`: обычный
прокси-режим работает без него. Драйвер ищется рядом с `Fluffify.exe`;
если запустить `Fluffify.exe` отдельно (например, скопировать только его
на рабочий стол), клиент сам распакует встроенную копию драйвера в
`%LocalAppData%\xray-tui\wintun.dll` и подхватит её — ничего копировать
не нужно.

Геобазы (`geoip.dat`, `geosite.dat`) в архив не входят — они крупные и нужны
только для правил роутинга по доменам/странам. Клиент скачает их сам:
Настройки → Роутинг → профиль → «Файлы геобаз» → «Скачать» (файлы лягут в
`%LocalAppData%\xray-tui\geo`). Если хочется положить их вручную — просто
скопируйте оба файла рядом с `Fluffify.exe`.

## Запуск

1. Распакуйте папку целиком куда угодно: рабочий стол, `D:\Fluffify`, флешка —
   без установки и без прав администратора.
2. Двойной клик по `Fluffify.exe`. Откроется окно TUI и иконка в трее.
   Первый запуск может показать SmartScreen («Windows защитила ваш компьютер»):
   файл не подписан — «Подробнее» → «Выполнить в любом случае».
3. Добавьте сервер любым из способов:
   - вкладка «Подписки» → «Добавить» → вставьте ссылку подписки → Enter;
   - окно добавления → режим «Ссылка» → вставьте ключ `vless://…`, `vmess://…`,
     `hysteria2://…` (можно пачку ключей, каждый с новой строки);
   - режим «JSON» → вставьте JSON-ноду или полный конфиг Xray.
4. Вкладка «Сервера» → выберите сервер → Enter, либо кнопка включения в шапке.

Готово: локальный SOCKS5 — `127.0.0.1:10808`, HTTP — `127.0.0.1:10809`.

### Вставка длинного текста

Клиент сам определяет, что вставлено: ссылка подписки (в том числе
URL-кодированная), ключ ноды, JSON или путь к файлу — в любом из полей.
Длинный вставленный текст не раздувает рамку: в поле показывается заглушка
`[вставлено N символов]`, а на разбор по Enter уходит полный текст.

### Мелочи интерфейса

- Флаги стран в названиях серверов показываются тегами (`🇱🇹 Литва` → `[LT] Литва`):
  Windows Terminal не рисует такие эмодзи, и строчка «разъезжалась».
- Длинные вставки (ключи, JSON, ссылки подписки) не ломают рамку: в поле видно
  `[вставлено N символов]`, полный текст уходит на разбор по Enter.

## Режимы

- **Proxy (по умолчанию)** — работает без прав администратора. Прокси слушает
  localhost, приложения подключаются к нему вручную или через настройки системы.
- **TUN** — весь трафик системы идёт через Xray. Права администратора нужны
  только демону: при первом запуске `Fluffify.exe`, если демон ещё не работает,
  Windows один раз спросит UAC и поднимет демон с правами (если демон уже
  запущен — ничего не спрашивается). Сам интерфейс всегда работает обычным
  процессом в вашем терминале. Перезапустить демон с правами вручную можно так
  же: «Демон от администратора» в трее или `Fluffify.exe restart-admin`.
  `wintun.dll` уже на месте.

## Автозапуск и трей

- Меню в трее: статус, «Подключить/Отключить», «Переподключить», серверы
  (список обновляется на ходу — новые ноды из TUI видны сразу, без перезапуска),
  роутинг, «Демон от администратора», открыть окно, выход.
- «Переподключить» мягко перезапускает Xray с текущим конфигом — удобно после
  добавления серверов или правок роутинга.
- Изменения роутинга в TUI применяются сами: правило после сохранения и смена
  активного профиля сразу пересобирают конфиг работающего Xray.
- Иконка отражает состояние и тему Windows:
  - тёмная тема: неактивно — тёмно-серый, активно — белый;
  - светлая тема: неактивно — светло-серый, активно — чёрный;
  - ошибка (нет связи с демоном, отказ сервера) — ярко-красный `#FF0000`.
  Состояние меняется на лету вместе с подключением и сменой темы.
- Если иконки не видно, проверьте скрытые значки (стрелка «^»).
- Автозапуск: Настройки → «Автозапуск системы». Клиент добавит себя в
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` и при входе в систему
  поднимет демон и трей без лишних окон. Демон при автозапуске обычный
  (без прав) — для TUN перезапустите его через «Демон от администратора».

## Где хранятся данные

| Что | Где |
|---|---|
| Профили, подписки, настройки | `%AppData%\xray-tui\store.json` |
| Скачанные geo-файлы (`Fluffify.exe geo update`) | `%LocalAppData%\xray-tui\geo\` |
| Локальный сокет демона | `%LocalAppData%\xray-tui\daemon.sock` |

Полное удаление: закройте трей (меню → «Выход») и удалите эти две папки.

## Командная строка

`Fluffify.exe <команда>` — работает из `cmd`/PowerShell:

```
Fluffify.exe status         показать статус
Fluffify.exe up 1           подключить профиль №1
Fluffify.exe add <ключ>     добавить ключ, подписку или JSON
Fluffify.exe down           отключить
Fluffify.exe logs -f        логи в реальном времени
Fluffify.exe tun-setup      проверить права для TUN
Fluffify.exe restart-admin  перезапустить демон от администратора (UAC)
```

## Если что-то не работает

- **TUN не запускается** — выберите «Демон от администратора» в трее или
  выполните `Fluffify.exe restart-admin`; `wintun.dll` уже рядом.
- **Подписка не грузится (403/404)** — откройте вкладку «Логи»: там виден код
  ответа, начало тела ответа сервера и отправленный User-Agent. Проверьте, что
  в поле User-Agent введено ровно то, что требует провайдер (например,
  `Happ/4.8.0/Android/...`).
- **Порт занят** — Настройки → «Порт SOCKS5» / «Порт HTTP», поменяйте на свободный.
- **Каша в консоли** — приложение само включает ANSI-режим и UTF-8 для окна;
  если запускаете в стороннем терминале, включите в нём поддержку UTF-8
  и виртуального терминала (например, Windows Terminal вместо старого conhost).
- **Антивирус ругается** — бинарник не подписан; добавьте папку в исключения
  или соберите сами (`build.sh`).
- **Подробные логи** — вкладка «Логи» в TUI или `Fluffify.exe logs -f`.

## Обновление ядра

Скачайте свежий `Xray-windows-64.zip` со
<https://github.com/XTLS/Xray-core/releases/latest>, замените в папке `xray.exe`
и `wintun.dll` (лицензии тоже стоит обновить). Файлы `geoip.dat` / `geosite.dat`
из того же архива нужны только для правил роутинга — положите их рядом с
`xray.exe`, если не хотите качать их через интерфейс.
Текущая версия записана в `Xray-version.txt`.

## Для сборки из исходников

```bash
./packaging/windows/make-icons.sh   # только при изменении SVG
./packaging/windows/build.sh        # иконка + VERSIONINFO + Fluffify.exe + zip с ядром
```

`build.sh` ожидает, что файлы ядра уже распакованы в `packaging/windows/`.
